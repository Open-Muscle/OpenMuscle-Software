# Using the Studio: guides

Pages for people who have the kit and want to record, train and predict. They assume
no programming.

| Page | Read it when |
|---|---|
| [getting-started.md](getting-started.md) | you are starting from the box |
| [studio-tour.md](studio-tour.md) | you want to know what every panel and button on the Studio page does |
| [first-model.md](first-model.md) | you are ready to record, train and try a model (about 15 minutes) |
| [movement-sheet.md](movement-sheet.md) | you want the movements for [first-model.md](first-model.md) on one printable page |
| [webcam-labeling.md](webcam-labeling.md) | you use the computer's camera to measure finger movement, or want to know which browsers work |
| [your-data.md](your-data.md) | you want to know where files are saved and how to back them up |
| [band-fit.md](band-fit.md) | you are putting the bands on |
| [wifi-setup.md](wifi-setup.md) | a band needs to join your Wi-Fi |
| [troubleshooting.md](troubleshooting.md) | something does not appear or does not work |
| [glossary.md](glossary.md) | a word is new to you |

For commands and options see [pc-cli.md](pc-cli.md). For how the files and the
network messages are laid out, see [data-schema.md](data-schema.md) and
[protocol.md](protocol.md).
